# Contributing to Cadence

Thank you for your interest in Cadence.

At this time, Cadence is not accepting external code contributions or pull requests.

If you discover a bug or have an idea for improvement, please use the built-in Help & Feedback section inside the application.

Ways to contribute:

- Report bugs
- Suggest features
- Provide usability feedback
- Share screenshots and reproduction steps

Thank you for helping improve Cadence.
